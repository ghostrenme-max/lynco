## 실제 연결 전투 · 카드 편집기 연동 (2026-09-29)

현재 전투에는 아래의 **승인된 테스트용 임시 규칙**을 적용합니다. 아래쪽의 예전 개발 기록 중 방향이 시각 전용이라는 설명, 고정 테이블 가치만으로 판정한다는 설명은 이 항목으로 대체합니다. 최종 밸런스와 세부 규칙은 아직 확정하지 않았습니다.

- 행동력은 카드의 기본 사용 비용입니다. 보유 큐브는 다음 턴으로 유지되며, 배치된 내 카드에 투자하거나 회수할 수 있습니다.
- 출발 카드의 방향에 있는 이웃 카드가 조건을 만족하면 그 **대상 카드의 주인**이 연결 효과를 받습니다. 상대 카드도 활용할 수 있지만 소유권은 바뀌지 않습니다.
- 기본 임시값: 시작 큐브 6, 두 번째 자기 턴부터 +1, 행동력 3. 투자 뒤 1턴 대기, 회수 비용 최대 1큐브. 투자금은 보유 큐브와 별도로 관리합니다.
- 30칸이 차거나 8번째 턴의 양측 행동을 마치면 판정합니다. 기본 판정은 보유 큐브 × 3 + 성과 × 1이며 투자금 인정률은 0%입니다. 같은 종합 점수는 무승부입니다.
- 전투 왼쪽 패널에서 보유/투자 큐브와 성과를 확인합니다. 테이블 내 카드를 클릭해 투자·회수하고, 손패를 선택해 빈 칸에 가져가면 예상 효과가 표시됩니다. 카드의 보라색 큐브는 투자 비용을 뜻합니다.
- 상대 AI도 같은 규칙을 따릅니다. 연결 효과는 각 이벤트마다 한 번씩 처리하며 연쇄 재귀 발동은 없습니다. 자기 턴 밖에서 받은 행동력은 다음 자기 턴에 지급합니다.
- 손패 5장 보충·최대 7장, 6×5 보드, 거울의 시각 복제 원칙은 유지합니다. 뒷면은 정체 공개만 적용하며 미정 효과는 실행하지 않습니다. 특전 선택과 런 진행은 이번 구현에 포함하지 않습니다.

**편집:** `D:\린코\LYNCO_Card_Editor.exe` → `실제 효과 · 조건` / `전투 규칙 · 임시값` → `게임 적용`에서 `D:\Lynco` 선택 → 게임 완전 종료 후 재실행.

기본/연결 효과·수치, 발동 시점, 대상 소유 조건, 투자 필수 여부, 투자 비용·보너스, 방향, 덱별 장수 및 전역 규칙을 바꿀 수 있습니다. 새 카드는 덱 장수를 지정해야 실제로 등장합니다. 지원 효과는 성과·큐브·행동력·드로우·없음입니다. 자유 입력 설명은 메모이며 코드를 생성하지 않습니다.

실제 데이터는 `data/battle_cards.json`입니다. 편집기는 적용 전 `.bak` 백업을 남기고 게임은 실행 시작 시 한 번 읽습니다. 잘못된 설정은 전체 거부하고 `data/default_battle_cards.json`으로 대체합니다. 자세한 사용법은 `tools/card_editor/README.txt`를 참고하세요.

- 상대 턴의 카메라 전환과 함께 두 덱이 플레이어 쪽(화면 아래, 기준 좌표 44px)으로 이동하고, 내 턴에는 복귀합니다. 일반 연출 0.46초, 간결한 연출 0.14초이며 추가 대기는 없습니다.
- 손패 최대 7장. 기본 시작/턴 보충은 기존 5장이고, 효과·추가 드로우로도 7장을 넘지 않습니다.

- 킹/조커 면에서는 비교 프레임을 숨깁니다. 기존 앞뒷면 연결과 전투 규칙은 그대로 유지합니다.

## 상세 카드 앞뒷면 설명
- 우클릭 상세창에서 카드를 좌클릭하면 반대 면의 이름·심볼·효과 설명·방향·가치 표시로 전환하고 다시 클릭하면 돌아옵니다. 실제 손패나 테이블 카드는 변경하지 않습니다.
- 뒷면 효과·비용·가치는 아직 미정이며 기존 미정 설명을 표시합니다. 우클릭/Esc/바깥 클릭 닫기는 유지합니다.

## 상황판·큐브 연출 보완
- 상황판 오른쪽의 큰 두 자리 숫자는 남은 행동력입니다. 턴/진행선은 위쪽, 테이블 배치 수는 왼쪽 아래, 턴 종료는 오른쪽 아래에 표시합니다.
- 상세창 큐브는 처음 0개로 시작하고 왼쪽부터 하나씩 나타납니다. 0.08초 동안 2배 확대, 0.10초 복원, 다음 큐브까지 0.05초 대기합니다. 첫 대기 0.05초 포함 5개는 약 1.2초입니다. 간결한 연출은 작은 확대를 유지합니다.

## 보라색 가치 큐브
- 숫자 배지를 보라색 큐브 0~5개의 가로 나열로 변경했습니다. 상세창은 오른쪽 위에 배치하며 우클릭으로 열 때마다 왼쪽부터 하나씩 확대·복원합니다.
- 연쇄의 테이블 가치를 6에서 5로 변경했습니다. EXE의 큐브 개수도 최대 5로 제한하고 미정 상태(-1)는 유지합니다. 0은 큐브를 그리지 않습니다.

## 손패 드래그 카메라
- 드래그 중인 카드 외의 손패는 아래로 200 디자인 픽셀 이동하여 윗부분만 남깁니다. 드롭·취소 시 원래 배치로 복귀하며 내려간 손패는 테이블 입력을 가로채지 않습니다.
- 좌클릭을 유지하여 손패를 테이블로 드래그할 때만 전방 확대와 제한된 마우스 추적이 작동합니다. 손패 선택 후 일반 호버는 기존 시점을 유지합니다.
- 확대 전 시점을 기준으로 범위를 판정하여 정지한 포인터에서 카메라가 밀리지 않습니다. 놓기/취소 시 이전 시점을 복원하고 테이블 밖에서는 부드럽게 복귀합니다.
- 드롭 칸은 확대된 현재 화면의 포인터로 판정합니다. 탑뷰·상세창·상대 시점에는 적용하지 않습니다.

## 최신 플레이 방식 — 테이블 판정·덱 상점 (2026-09-27)

아래 이전 날짜/같은 날짜의 기록보다 이 항목이 우선합니다. 체력 전투에서 테이블 점수 대전으로 전환한 시제품입니다.

- 각 내부 핵에서 작은 보라색 입자 18개가 반복 발산합니다. 중력 없이 약 1.8초간 천천히 짧게 이동하고 끝에서 투명해져 사라집니다.
- 이동 최대 범위는 핵 중심에서 로컬 약 0.34(큐브 반폭 0.5 이내)이며 장거리 궤적이나 잔상은 없습니다. 입자는 고정 풀을 재사용합니다.
- 상대 카드가 내 테이블로 이동하는 동안 방향 탭은 숨기고, 완전히 안착하면 표시합니다.
### 임시 아이템 확인
- 전투 화면에서 숫자패드 0을 누르면 임시 아이템 6개(일반 상점 3개, 암시장 3개)를 보유 목록에 추가합니다. F로 확인하며 열린 목록은 즉시 갱신됩니다.
- 반복 입력은 중복 추가하지 않고 기존 보유 아이템을 보존합니다. 키보드 윗줄 0에는 반응하지 않습니다. 테스트 아이템에는 효과·가격이 없고 세션 종료 시 초기화됩니다.

## 보유 아이템 중앙 선택 목록
- F 목록에서 휠 한 칸마다 선택이 이동합니다. 선택 항목은 항상 목록 중앙에서 가장 크고 밝으며, 멀어질수록 크기와 밝기가 감소합니다. 클릭 및 스크롤바로도 선택할 수 있습니다.
- 0.18초 이동, 처음/마지막 항목 중앙 유지, 목록과 스크롤바 사이 여백. 아이템 규칙과 세션 데이터는 기존 방식 유지.

## 카드 데이터 편집기
- `tools/card_editor/build.ps1`로 독립형 Windows EXE를 빌드합니다. 실행 파일과 HTML 목록은 `D:\린코`에 배치합니다.
- 카드 이름·설명·비용·점수·색상·8방향 편집, JSON 저장/불러오기, 독립 HTML 생성, Godot `.tres` 내보내기를 지원합니다.
- 기본 데이터는 현재 카드 앞면 6종과 뒤집힌 면 6종입니다. 미정 수치는 -1로 구분합니다.
- 내보낸 `lynco_cards`를 대상 Godot 프로젝트 루트에 복사합니다. 설명 데이터와 전투 효과 실행 코드는 별개이며 기존 게임 정의를 자동 변경하지 않습니다.
- 상세 안내: `tools/card_editor/README.txt`. 검증: EXE `--test <출력폴더>`, Godot `export_test.gd`.
