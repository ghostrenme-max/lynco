LYNCO 카드 편집기 — 실제 게임 규칙 연결

실행: LYNCO_Card_Editor.exe
같은 폴더의 카드목록.json을 자동으로 불러옵니다. 구형 JSON은 기존 이름·설명·방향 등을 유지하며 새 임시 규칙 필드를 보완합니다.

1. 기본 정보: 이름, 설명 메모, 행동 비용, 색상, 심볼, 방향을 편집합니다.
2. 실제 효과·조건: 기본 효과/수치, 연결 효과/수치, 연결 대상(양측·같은 소유자·다른 소유자), 발동 시점, 투자 필수 여부, 투자 큐브 비용, 투자 추가 수치를 편집합니다.
3. 기본 덱/상대 덱 장수: 앞면 카드별 0~30장, 각 덱 합계 5~60장입니다. 새 카드/복제는 기본적으로 덱 장수 0이며, 장수를 지정하면 실제 게임에 등장합니다.
4. 전투 규칙·임시값: 시작/턴 지급 큐브, 행동력, 최대 턴 수, 큐브/성과 점수 배수, 회수 대기/비용, 최종 투자금 인정 비율을 편집합니다.
5. 게임 적용: D:\Lynco처럼 project.godot이 있는 프로젝트를 선택합니다. data/battle_cards.json에 반영하고 편집기 옆 카드목록.json도 저장합니다. 기존 파일은 .bak로 보존합니다.
6. 실행 중인 게임을 종료하고 다시 실행하세요. 전투 도중 데이터가 바뀌지 않도록 실행 시작 시 한 번만 읽습니다.

임시 기본 규칙
- 시작 큐브 6, 두 번째 자기 턴부터 큐브 +1, 턴 행동력 3.
- 30칸이 차거나 8번째 턴의 양측 행동이 끝나면 판정.
- 종합 점수 = (보유 큐브 + 인정 투자금) × 3 + 성과 × 1.
- 투자금은 보유 큐브와 별도. 기본 최종 인정 비율 0%이며, 이 값은 수정할 수 있습니다.
- 투자 후 최소 1턴을 기다려 회수. 회수 비용은 투자금 내에서 최대 1큐브. 같은 턴 재투자 금지.
- 연결 효과는 출발 카드의 방향에 있는 바로 이웃 카드의 주인에게 지급. 상대 카드도 조건에 맞으면 이용합니다. 소유권은 이전하지 않습니다.
- 발동: 대상 카드 배치 / 출발 카드 투자 / 대상 주인의 턴 시작 / 세 경우 모두.
- 투자하면 출발 카드의 연결 수치가 투자 추가 수치만큼 증가. 투자 필수가 체크되면 투자 전에는 발동하지 않습니다.
- 성과·큐브·행동력·드로우·없음만 실행 효과로 지원합니다. 각 이벤트의 연결을 한 번씩 처리하며 효과가 효과를 재귀 호출하지 않습니다.
- 자기 차례가 아닐 때 받은 행동력은 다음 자기 턴 보너스로 보관합니다. 드로우는 손패 최대 7장까지 적용합니다.
- 상대 AI도 같은 규칙을 사용합니다. 간단한 연결 활용·투자·후반 회수 정책이며 최적 전략 AI는 아닙니다.

게임에서 테이블 카드를 클릭하면 왼쪽 패널에서 투자/회수가 가능합니다. 보유·투자 큐브와 성과는 패널에 표시됩니다. 손패 선택/드래그 시 배치 지점의 기본·연결 예상 효과를 확인합니다.
카드의 보라색 큐브 표시 = 투자 비용. 테이블 카드 옆 보라색 표시는 현재 투자금입니다. 골드는 상점용 별도 재화입니다.

설명 메모나 구형 효과 ID를 입력한다고 새 효과 코드가 생성되지는 않습니다. 실제 효과·조건 탭의 선택값이 실행됩니다.
구형 큐브/효과 필드는 기존 데이터를 보존하기 위한 메타데이터입니다. 상태 메모(Y/N)는 실행 여부를 제어하지 않습니다.
뒷면은 정체 공개만 유지합니다. 뒷면의 실행 효과와 덱 장수는 적용하지 않습니다.

JSON 저장: 편집 원본만 저장합니다. 실제 게임 반영은 게임 적용을 사용하세요.
HTML 저장: 현재 카드 목록을 별도 문서로 저장합니다.
Godot 내보내기: 새 날짜 폴더에 전체 cards.json(전투 설정 포함)과 lynco_cards/*.tres 리소스를 생성합니다. 리소스 복사만으로 게임 설정이 바뀌지는 않습니다. 현재 게임에는 게임 적용 버튼을 사용하세요.

유효하지 않은 설정은 적용 단계에서 차단합니다. 게임에서 파일 오류를 발견하면 전체 편집 설정을 거부하고 번들 기본값으로 실행하며 알림을 표시합니다.
이 수치와 효과는 사용자가 승인한 테스트용 임시 규칙입니다. 밸런스 확정값이 아닙니다.
