# 카드 뒷면 디자인

내장 image_gen 도구로 생성. 원본 참고: LYNCO_S05_r01_c10.png(흰 카드), LYNCO_S05_r05_c01.png(검은 카드).
게임은 이 폴더의 card_back_white.png 및 card_back_black.png를 덱과 드로우 카드에 공용으로 사용한다. 둥근 모서리는 공용 셰이더로 처리하며 기존 드로우 시간은 유지한다.

최종 생성 프롬프트: 평면 2D LYNCO 카드 뒷면, 세로 158:228 비율, 캔버스를 가득 채우는 카드, 원근·목업·외부 여백·그림자 없음. 모서리 반경 너비의 8%, 얇은 안쪽 테두리, 넓은 여백. 참고 로고의 윤곽과 내부 구멍을 유지하고 정중앙에 배치, 폭 약 36%, 높이 30% 이내. 글자·숫자·추가 문양·그라데이션 없음.

- 흰 카드: 불투명 흰 바탕, 검은 테두리와 검은 로고. 흰 표면이 투명해지지 않도록 지정한 재생성본 사용.
- 검은 카드: 검은 바탕, 흰 테두리와 흰색으로 변환한 로고.

원본 생성 이미지를 PNG로 보관하고, Godot 임포트 크기는 최대 512픽셀로 제한한다.
