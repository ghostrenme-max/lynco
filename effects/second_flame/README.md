# 린코(LYNCO) — 첫 번째 불꽃 (수정본)

제공 영상 전반의 둥근 하단을 가진 불꽃과 추가로 제공한 이미지을 참고한 절차적 셰이더 이펙트입니다. 원본 프레임을 복사한 스프라이트가 아니라 곡선, 패임, 속불, 불씨를 실시간 계산합니다.

## 사용

- 2D: `res://effects/second_flame/flame_2d.tscn`을 원하는 씬에 드래그합니다. 원점은 불꽃 바닥이며 노드 scale로 크기를 조절합니다.
- 3D: `res://effects/second_flame/flame_3d.tscn`을 드래그합니다. 카메라를 향하는 빌보드이며 기본 쿼드 크기는 2×2입니다.
- 미리보기: `preview.tscn`을 열고 F6을 누릅니다.
- 다른 프로젝트로 옮길 때 `effects/second_flame` 폴더와 경로를 그대로 유지합니다.

## 조절

루트 노드 Inspector:
- `speed`: 기본 3.5. 초안 대비 3.5배 속도. 0은 정지입니다.
- `phase`: 여러 불꽃이 동시에 같은 모양이 되지 않도록 시간차를 지정합니다.
- `playing`: 자동 재생. false일 때 `seek(seconds)`로 특정 시각을 지정할 수 있습니다. seek는 배속이 적용되기 전 셰이더 시각을 받습니다.

Surface의 ShaderMaterial 파라미터:
- `wiggle_strength`: 기본 1.0. 몸통과 끝의 서로 다른 주기를 합친 wiggle입니다. 0이면 추가 흔들림이 없어집니다.
- `glow_strength`: 기본 1.1. 넓은 주황색 외곽광과 가까운 광륜, 바닥광을 함께 조절합니다.
- `outer_color`, `core_color`, `core_size`: 외곽색, 속불색, 속불 크기.

각 인스턴스는 독립된 머티리얼을 사용합니다. 2D/3D 모두 에디터에서도 움직입니다. 텍스처, 외부 플러그인, HDR bloom 없이 GL Compatibility에서 동작합니다. 글로우는 투명 쿼드 안에서 계산하는 시각 효과로 주변 3D 물체를 실제로 밝히지는 않습니다. 실제 조명이 필요하면 별도 OmniLight3D를 사용하세요.

## 확인

Godot 4.7.1 / OpenGL Compatibility / NVIDIA GTX 1060에서 2D GPU 렌더링 및 3D 빌보드 렌더링, 서로 다른 배율과 위상, 머티리얼 독립성을 확인했습니다. GIF는 실제 Godot 화면을 28fps로 캡처한 약 7.71초 반복 영상입니다. 기본 배속에서는 약 0.857초마다 한 주기가 반복됩니다.

기존 전투나 촛불 씬에는 자동 연결하지 않고 독립 이펙트로 추가했습니다.

파일 경로 `second_flame`은 기존 리소스 참조 유지를 위해 그대로 두었으며, 내용은 첫 번째 불꽃 형태로 수정했습니다. 하단은 평평하게 잘리지 않고 둥글게 닫힙니다.

작은 불씨는 10개의 독립 생성 경로에서 크기·기울기·수명·출발 위치·흔들림이 달라집니다. 속이 찬 물방울/불꽃 조각 형태이며, 상승하면서 축소·소멸합니다. 의사 난수 시드로 재현 가능하며 불씨 전체 주기는 셰이더 시간 27초(3.5배속에서 약 7.71초)입니다. 메인 불꽃의 형태 함수와 배속은 이 수정에서 변경하지 않았습니다.
